# Ford GoBike Exploratory Data Analysis

A Python-based exploratory data analysis project using the Ford GoBike bike-sharing dataset.

## Project Overview

This project focuses on cleaning, preparing, and exploring Ford GoBike trip data using Python. The analysis covers data inspection, handling duplicated records, checking missing values, converting data types, creating new features, and exploring relationships between different variables through visualizations.

The project was developed using Jupyter Notebook and focuses on practical data preprocessing and exploratory data analysis techniques.

## Dataset

The project uses the Ford GoBike dataset containing information about bike-sharing trips and users.

The dataset contains information related to bike trips, including trip duration, start and end times, stations, user type, member gender, and bike-sharing program usage.

## Objectives

The main objectives of this project are to:

* Inspect and understand the dataset.
* Identify missing values and duplicated records.
* Examine data types and unique values.
* Clean and prepare the dataset for analysis.
* Create additional features from the available data.
* Explore numerical and categorical variables.
* Analyze bike-sharing usage patterns.
* Visualize distributions and relationships between variables.
* Extract meaningful insights from the dataset.

## Data Preprocessing

The preprocessing stage includes:

* Loading the dataset.
* Inspecting the dataset structure and dimensions.
* Checking data types.
* Checking for missing values.
* Checking for duplicated rows.
* Exploring unique values in categorical columns.
* Handling missing and inconsistent data.
* Converting appropriate columns to suitable data types.
* Creating new variables from existing date and time information.
* Preparing the dataset for exploratory analysis.

## Exploratory Data Analysis

Several visualizations were used to understand the dataset and identify patterns.

### Distribution Analysis

The project explores the distribution of numerical variables using:

* Histograms
* KDE plots
* Box plots

These visualizations help understand the distribution, spread, and potential outliers in the data.

### Categorical Analysis

Categorical variables were explored using:

* Count plots
* Bar plots
* Pie charts

This helps understand the frequency and distribution of different user and trip categories.

### Relationship Analysis

Relationships between variables were explored using:

* Scatter plots
* Pair plots
* Bar plots
* Line plots
* Correlation heatmaps

These visualizations provide a better understanding of relationships and patterns within the Ford GoBike dataset.
